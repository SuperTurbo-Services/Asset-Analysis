# Event driven Market Overview — brand spec

Inherited from the approved SuperTurbo `Total View Wealth` direction on 2026-09-01.

## Fixed identity

- Typographic `ST` / `SuperTurbo` mark; there is no dedicated image logo for this surface.
- Warm paper ground, white surfaces, ink text, restrained navy structure, semantic green and red.
- Editorial serif only for page-level framing; body and controls use a legible system sans; numbers use tabular figures.

## Palette

- Paper: `#F5F3EE`
- Surface: `#FFFFFF`
- Navy: `#183249`
- Ink: `#191713`
- Secondary: `#5D5A54`
- Rule: `#DDD9D1`
- Positive: `#177A50`
- Negative: `#C13F48`
- Caution: `#A06C13`

## Interaction rules

- Event names must be plain-language situations rather than internal model labels.
- Every slider shows its value and unit.
- Selecting an event changes all four asset cards in the same visible frame.
- The selected event is unmistakable and manual slider changes switch the state to `Custom scenario`.
- No compact ticker-score strip appears in any direction.
- Body text is at least 14px and labels are at least 12px.

## Direction sources

- Direction A follows the required roulette result: Pure CSS geometric art, adapted as an event compass rather than decoration.
- Direction B transfers the verified Aleta/Etops total-view principle into a horizontal event rail and four-outcome board.
- Direction C applies an IDEO-style scenario-card workflow: start from a human question, reveal assumptions, then compare consequences.
